Website Design & Development

studyKora

studyKora is a competitive-exam preparation website designed to organise subject-wise MCQs, mock tests, daily practice and current affairs.

Design and Develop by Yadav Web Technologies

Design and Interface

The website uses a shared design system with green primary colours, light-green highlights, reusable cards, responsive layouts and consistent typography.

Shared interface styling and common browser interactions are managed through the website's shared stylesheet and JavaScript.

Educational Content

Educational questions, explanations, study notes and current affairs should be reviewed for accuracy before publication. Sample questions currently used to test the interface are illustrative and should not be treated as official examination papers.

Third-party educational material, if added later, should include appropriate attribution and be used in accordance with its licence and applicable law.

Technology and Services

The current frontend uses standard web technologies, including HTML, CSS and JavaScript.

Firebase Authentication and database services are planned for later integration. Their use and associated attribution should be confirmed when the integration is implemented.

Third-Party Assets

Any external fonts, libraries, icons, images or other assets added to the project should be identified here with their source and licence where attribution is required.
