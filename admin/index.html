Import Subjects

Paste a JSON array of subject objects. Each item requires id and name.

Schema example 
[
  {
    "id": "general-knowledge",
    "name": "General Knowledge",
    "description": "Static GK and important facts",
    "category": "General Studies",
    "about": "Longer description...",
    "tags": ["General Studies", "MCQ Practice"],
    "topics": ["Static GK", "Important Days"],
    "published": true
  }
]

Import Tests

Paste a JSON array of full test objects. Each test requires id, title, subjectId (must exist), and questions (non-empty).

Schema example 
[
  {
    "id": "assam-vfa",
    "title": "Assam VFA Exam",
    "subjectId": "general-knowledge",
    "description": "Village Field Assistant practice",
    "category": "recruitment",
    "duration": 600,
    "marksPerQuestion": 1,
    "published": true,
    "questions": [
      {
        "question": "Which city is the capital of Assam?",
        "options": ["Guwahati", "Silchar", "Dispur", "Jorhat"],
        "answer": 2,
        "explanation": "Dispur is the capital of Assam."
      }
    ]
  }
]

Import MCQs (append to existing test)

Paste a JSON array of question objects. They will be appended to the selected test.

Schema example 
[
  {
    "question": "What is 2 + 2?",
    "options": ["3", "4", "5", "6"],
    "answer": 1,
    "explanation": "2 + 2 = 4."
  }
]
