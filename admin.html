Import questions from JSON

Paste a question array or a full test object. Every entry is validated before import.

JSON format 
General MCQ
{ "q": "Capital of Assam?", "options": ["Guwahati", "Dispur", "Jorhat", "Tezpur"], "answer": 1 }

Full test wrapper (optional)
{ "title": "Mock Test 1", "minutes": 30, "questions": [ ... ] }
  • q — required, English text
  • options — exactly 4 strings
  • answer — 0 to 3 (A=0, B=1, C=2, D=3)
  • hint — optional, English text (auto-translated to Assamese)
